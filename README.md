👋 About Me

Hi, I'm Md. Rafiul Islam — an IoT & Robotics Engineering undergraduate who enjoys building at the intersection of embedded systems, backend engineering, AI, and robotics.

I like taking an idea from a circuit or sensor all the way to a usable software system: firmware on the device, APIs in the backend, data in a database, and an interface that makes the whole thing useful.

🔌 Building with ESP32, Arduino, sensors, RFID, GPS, and embedded systems

⚙️ Interested in backend engineering, scalable REST APIs, system design, and clean architecture

🧠 Exploring Machine Learning, Computer Vision, LLM-powered applications, and AI integration

💻 Practicing competitive programming, problem solving, and core CS fundamentals

🤖 Building IoT prototypes, robotics projects, and real-world automation systems

🎬 I also enjoy video editing and turning raw footage into something worth watching

📚 Outside code: books, travel, photography, and discovering new ideas

My goal: build reliable systems where hardware, software, and intelligence work together.
